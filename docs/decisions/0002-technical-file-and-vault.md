# ADR-0002: پرونده فنی شرکت‌ها، گاوصندوق پسورد و آمادگی برای پنل مدیریت

## Status
Accepted (تصمیم مالک، نسخه 1.4.0)

## Date
2026-10-12

## Context
مالک می‌خواهد مشخصات فنی هر شرکت (سیستم‌های قابل دسترسی با نحوه اتصال/آدرس/یوزر/پسورد، ریموت‌های AnyDesk/RustDesk، دامین یا ورک‌گروپ، سرورهای فیزیکی ESXi، سرورها، برنامه‌ها، کاربرها) در اپ ثبت شود و بعداً یک پنل مدیریت برای مدیرهای مجموعه روی سرور (VPS یا سرور شرکت، هنوز تصمیم نگرفته) آن را ببیند و مدیریت کند. مالک تأکید کرد قبل از انتشار و رفتن روی سرور، امنیت و دسترسی‌ها باید کامل و بی‌نقص باشد.

## Decision
1. **پرونده فنی** داخل تب ساپورت است (سوئیچ «گزارش کار / پرونده فنی») و هیچ بخشی از آن وارد پیام واتساپ، پیام‌رسان، اکسل یا گزارش نمی‌شود.
2. **یک رمز اصلی برای همه پسوردها** (مثل Google Password Manager)، نه رمز جدا برای هر رکورد. پیشنهاد اولیه «رمز برای هر رکورد» نبود؛ مالک صریحاً همین مدل را تأیید کرد.
3. پسوردها با PBKDF2-SHA256 (۳۱۰٬۰۰۰ دور) + AES-GCM-256 رمز می‌شوند؛ قفل خودکار با رفتن به پس‌زمینه یا ۵ دقیقه بی‌کاری؛ ۵ رمز اشتباه = ۳۰ ثانیه صبر؛ نمایش ۱۰ ثانیه‌ای؛ کلیپ‌بورد بعد از ۳۰ ثانیه پاک می‌شود. فراموشی رمز اصلی = از دست رفتن پسوردها (عمداً راه بازیابی ندارد).
4. **پنل مدیریت در داکر** ساخته خواهد شد تا روی ویندوز (Docker Desktop)، VPS یا سرور شرکت یکسان اجرا شود. ساخت سرور، پنل و نسخه ویندوز به مرحله بعد موکول شد؛ الان فقط زمینه داخل اپ آماده شد (شناسه یکتا، زمان تغییر، حذف نرم؛ `docs/data-model.md`).
5. **سرور فقط متن رمزشده را نگه می‌دارد** (رمزنگاری سرتاسری)؛ رمز اصلی هیچ‌وقت به سرور فرستاده نمی‌شود.

## برای مرحله سرور (قبل از انتشار باید طراحی و بازبینی امنیتی شود)
- حساب جدا برای هر مدیر/تکنسین، نقش‌ها (مدیر کل، مدیر، تکنسین فقط‌خواندنی) و دسترسی به تفکیک شرکت.
- ورود دومرحله‌ای، لاگ دسترسی (چه کسی کدام پسورد را دید)، HTTPS اجباری، محدودیت تلاش ورود.
- اشتراک پسوردها بین چند کاربر: کلید گاوصندوق برای هر کاربر با کلید خودش رمز شود (مدل Bitwarden) تا سرور هیچ‌وقت متن ساده نبیند.

## Alternatives Considered
- **رمز جدا برای هر رکورد:** مالک رد کرد؛ استفاده روزمره را سخت می‌کند.
- **پسورد بدون رمزنگاری:** هر کس به گوشی یا فایل پشتیبان دسترسی داشت همه پسوردها را می‌دید.
- **پسورد فقط در پنل:** تکنسین سر کار به آن نیاز دارد؛ مالک ورود از گوشی و پنل هر دو را خواست.

## Consequences
- فایل پشتیبان پسورد خوانا ندارد؛ برای استفاده روی گوشی دیگر همان رمز اصلی لازم است.
- حذف شرکت از لیست محل‌ها پرونده فنی‌اش را پاک نمی‌کند (با اضافه کردن دوباره همان نام برمی‌گردد).
