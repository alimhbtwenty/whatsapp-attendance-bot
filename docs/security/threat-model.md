# مدل تهدید Geo Team (نسخه 1.4، پیش از سرور)

## دارایی‌ها
| دارایی | کجا | حفاظت |
|---|---|---|
| پسوردهای پرونده فنی (سیستم‌ها، ریموت‌ها، سرورها) | `geomat_inventory_v1` → `secrets` و `history[].secrets` | AES-GCM-256 با «کلید تیم»؛ هیچ‌وقت متن ساده ذخیره یا لاگ نمی‌شود |
| کلید تیم | `geomat_team_v1` → `users[].wrapped` | برای هر کاربر با PBKDF2-SHA256 (۳۱۰٬۰۰۰ دور) از رمز خودش قفل شده؛ در حافظه فقط بعد از ورود |
| رمز حساب‌ها | هیچ‌جا | فقط با باز شدن `wrapped` بررسی می‌شود |
| تاریخچه پرونده فنی (ضد خرابکاری) | `history` فقط-افزودنی | `pushVersion()`؛ بازگردانی پشتیبان ادغام می‌کند؛ حذف فقط مدیر و نرم |
| آرشیو تردد، چت، تنظیمات، مشخصات غیرمحرمانه پرونده فنی | localStorage | sandbox اندروید + قفل برنامه (رمزنگاری در حال سکون ندارد؛ پایین را ببینید) |
| کلید بیومتریک | اندروید: Android Keystore؛ وب: `geomat_bio_v1` | Keystore: فقط با BIOMETRIC_STRONG، با ثبت اثر انگشت جدید باطل؛ وب: کلید از PRF پس‌کلید پلتفرم |

## ریسک‌های پذیرفته‌شده تا آمدن سرور (صادقانه)
1. **داده غیرمحرمانه رمزنگاری در حال سکون ندارد.** هر کس با دسترسی root یا ابزار فنی به حافظه برنامه، آرشیو و مشخصات غیرپسوردی پرونده فنی را می‌خواند. پسوردها همچنان رمزشده‌اند.
2. **نقش‌ها روی گوشی خود کاربر در رابط برنامه اعمال می‌شوند.** کسی که کد را روی گوشی خودش دستکاری کند می‌تواند داده **همان گوشی** را عوض کند. پسورد بدون کلید تیم خواندنی نیست، و تاریخچه گوشی‌های دیگر و پشتیبان‌ها ادغام‌پذیرند. اجرای قطعی نقش‌ها و تاریخچه غیرقابل پاک‌شدن کار سرور است.
3. **`android:allowBackup="true"`:** پشتیبان خودکار گوگل ممکن است داده برنامه را (رمزشده با حساب گوگل) نگه دارد. این فعلاً تنها راه نجات داده برای کاربرانی است که فایل پشتیبان نمی‌گیرند. با آمدن سرور خاموش شود (`docs/security/server-checklist.md`).
4. **بیومتریک وب** فقط در مرورگرهایی با پس‌کلید و PRF کار می‌کند؛ بقیه فقط رمز دارند.
